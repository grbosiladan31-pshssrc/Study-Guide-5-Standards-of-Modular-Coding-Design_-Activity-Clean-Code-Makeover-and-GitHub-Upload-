# Distance Calculator

## Description
The repository has a simple and clean Python program that calculate the distance between two points on a Cartesian Plane. 

## Features
* This Python code uses built-in `math` module and `pow()` function.
* Implements clear variable names (`x_1`, `x_2`, `y_1`, `y_2`) for easy reading.
* Prompts/asks the user for interactive coordinate inputs.

## How to Run the Program
1. Make sure you have python installed.
2. Run the script using your terminal or Python environment:
   ```bash
 python distance_calculator.py

## Sample Input & Output
Input:
Enter x_1: 9
Enter x_2: 7
Enter y_1: 4
Enter y_2: 1

Output: The distance is: 3.605551275463989
